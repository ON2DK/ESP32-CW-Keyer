# KiCad source files

The editable KiCad V2 source archive is stored in this folder:

- `ESP32_CW_KEYER_V2_KiCad_Source.zip`

Open the archive in KiCad and keep the project-local footprint library together with the project files. The design uses a custom/project-local 38-pin ESP32 DevKit footprint.

Before editing or producing a revised PCB, refill copper zones and run DRC plus schematic/PCB parity checks again.

# Documentation

Project documentation for the ESP32 CW Keyer belongs here, including the project logbook, BOM, assembly notes and connector/pin information.

Important assembly checks include:

- verify transistor pinouts against the purchased parts
- verify diode, LED and electrolytic capacitor polarity
- verify 12 V, 5 V and 3.3 V rails before inserting sensitive modules
- test CAT, KEY and PTT separately before connecting a transceiver
- keep the ESP32 antenna keep-out area clear

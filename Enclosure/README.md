# Enclosure

3D-printable enclosure files and editable OpenSCAD sources for the ESP32 CW Keyer belong in this folder.

The Keyer enclosure is different from the Trainer enclosure because the PCB size, mounting positions and front/rear panel functions differ.

Before final printing, verify all panel hole diameters and positions against the actual connectors, switches, encoder, potentiometer and TFT module you will use.
